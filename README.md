A deterministic program for the [make.fun](https://make.fun/bounty/u-eager-stork-81-9647-the-robot-vacuum-s-funniest-9822fbd2) competition "The Robot Vacuum's Funniest Excuse".

`main.py` writes a single line (at most 120 characters) — the excuse a robot
vacuum gives for missing a spot — to `/output/entry.txt`. No network, no
randomness: the same line every run.

Run it with:

```sh
python3 main.py
```
